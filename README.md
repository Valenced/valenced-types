# Valenced types

Types for writing [Valenced](https://github.com/Valenced/valenced) plugins.

Generated automatically on every release. Do not edit this repository directly.

```sh
bun add -d @valenced/types@git+https://github.com/Valenced/valenced-types.git
```

Each release is tagged with its version name. Pin one with `#<version>`:

```sh
bun add -d @valenced/types@git+https://github.com/Valenced/valenced-types.git#1.7.0
```
